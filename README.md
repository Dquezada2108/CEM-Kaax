# Kaax · Equipo CEM

Sitio del equipo. Kaax es una flota de robots acuáticos que recolecta lirio,
sargazo y residuos de presas, lagos y costas.

**Equipo CEM** — Tecnológico de Monterrey, PrepaTec Campus Estado de México.

🌐 https://dquezada2108.github.io/CEM-Kaax/

## Estructura

Una sola página, sin dependencias de compilación. `index.html` lleva el HTML,
el CSS y el JS; three.js se carga desde CDN para los dos visores 3D.

`assets/` contiene el logotipo, el modelo `kaax.glb`, las fotos de campo y las
capturas de la estación de control.
